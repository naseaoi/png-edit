# PNG 批量图片处理器

一个基于 Next.js 的 Web 应用，用于批量处理 PNG 图片，支持添加背景色、添加透明边框等功能。

## 功能特性

- **批量上传**：支持拖拽或点击选择多个 PNG 图片
- **背景颜色**：预设多种绿幕/蓝幕颜色，支持自定义颜色
- **透明边框**：可为图片添加自定义宽度的透明边框（上下左右分别设置）
- **批量处理**：一键处理所有图片
- **撤销功能**：支持单张撤销和全部撤销
- **批量下载**：支持单张下载或打包下载为 ZIP

## 技术栈

- **框架**：Next.js 15 + React 19
- **UI 组件**：shadcn/ui
- **样式**：Tailwind CSS
- **打包**：JSZip（ZIP 文件生成）
- **图标**：Lucide React

## 使用说明

### 1. 上传图片

- 点击上传区域选择 PNG 图片
- 或直接将 PNG 图片拖拽到上传区域
- 支持批量上传多张图片

### 2. 设置背景颜色

- 从预设颜色中选择（标准绿幕、影视绿幕、蓝幕等）
- 或使用自定义颜色
- 选择的颜色会作为图片的背景色

### 3. 添加透明边框（可选）

- 启用"透明边框"开关
- 分别设置上、下、左、右的边距数值（像素）
- 边框区域将保持透明
- 适用于需要在图片周围留出透明区域的场景

### 4. 处理图片

- 点击"开始处理"按钮处理所有图片
- 可在进度条查看处理进度
- 处理完成后图片会显示"已完成"标记

### 5. 下载结果

- 单张图片：点击图片下方的"下载"按钮
- 全部下载：点击"下载全部"打包下载 ZIP 文件

### 6. 撤销操作

- 单张撤销：鼠标悬停在图片上，点击右下角的撤销按钮
- 全部撤销：点击控制面板中的"撤销全部"按钮

## 颜色预设

| 名称 | 颜色值 | 描述 |
|------|--------|------|
| 标准绿幕 | #00FF00 | 经典绿幕 |
| 影视绿幕 | #00B04F | 专业绿幕 |
| 蓝幕背景 | #0000FF | 标准蓝幕 |
| 纯白背景 | #FFFFFF | 纯白色 |
| 纯黑背景 | #000000 | 纯黑色 |

## 输出格式

- 处理后的图片保存为 JPG 格式
- 质量：90%
- 透明边框功能启用时，背景色将被跳过，保留透明区域
